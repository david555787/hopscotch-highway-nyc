# Hopscotch Highway · NYC After Hours

A browser-based, Crossy Road-style arcade game set in New York after dark. Guide a little chicken through traffic, subway tracks, rivers, and glowing city streets.

## Play locally

Open `index.html` in a browser, or serve the repository as a static website.

## Controls

- Arrow keys or WASD to move
- On-screen controls are available on touch devices

## Project files

- `index.html` — game interface, world generation, movement, and collision logic
- `art.js` — illustrated sprite renderer
- `nyc-atlas.png` — NYC taxis, buildings, trees, and subway artwork
- `world-atlas.png` — player and environment artwork
